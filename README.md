# 💗 Pour toi — Mini-site de salutation romantique

> Un petit site doux, interactif et responsive pour dire à quelqu’un de spécial
> à quel point elle compte. HTML, CSS et JavaScript natifs — aucune dépendance.

---

## ✨ Parcours

1. **`index.html`** — Salutation tendre et accroche romantique.
2. **`page2.html`** — Confession : « Tu comptes plus que tout » + boutons
   **Oui** / **Non** (le Non s’enfuit).
3. **`page3.html`** — Finale séduisante, photos, cœurs animés et musique.

---

## 🚀 Lancer

Ouvre `index.html` dans un navigateur (Chrome, Firefox, Safari, Edge).

```bash
# Windows
start index.html
```

---

## 📱 Responsive

Conçu pour **téléphone**, **tablette** et **PC** (de ~320 px à 1920 px+),
avec typo fluide (`clamp`), safe-area iOS et boutons tactiles.

---

## 🎨 Personnalisation rapide

| Fichier | Contenu |
|---------|---------|
| `index.html` | Accueil / salutation |
| `page2.html` | Déclaration + question |
| `page3.html` | Message final + photos |
| `js/script.js` | Textes du bouton « Non » |
| `css/style.css` | Couleurs (`:root`) |
| `assets/` | Musiques + photos |
